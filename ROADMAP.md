# Road to 1.0

Where Quiznight? is heading until the first proper quiz night. Ticked items are done (some arrive with the next
update); the rest is planned. Plans can change: whatever turns out not to be fun gets changed or removed.

**How versions go from here**
- **0.9.x** — polish: bugs, smaller annoyances, quality of life, a tidier look.
- **0.10.0** — only if something new is big enough to deserve its own version (a maybe, not a plan).
- **1.0.0** — the first proper quiz night. The real Ewige Tabelle starts here; nights before count for the Beta table.

## 0.9.x — polish

### Editor
- [x] Estimation units as a drop-down (SI, light years, AU, horsepower …), your own still possible
- [x] Decimals with dot or comma, every digit kept
- [x] Points per place with presets (F1 old and new, MotoGP, IndyCar, NASCAR, Mario Kart) or your own

### Quality of life
- [x] "How it works" on the players' Get ready screen, with a "Tonight so far" tab
- [x] Stats for the night (Stats link next to the scores, for host and players)
- [x] Ewige Tabelle: sort by any column, profile pictures, average % off for estimations
- [x] Tie rule "Faster answer wins" (the default for new map pins)
- [x] Choice questions: optional "Wrong answers cost points"
- [x] The game looks for updates every minute while it's open; "Update to …" in the editor and quiz screens
- [x] Match history (quiz, host, date, places) next to the Ewige Tabelle; your own name in bold in both

### Tested with real people
- [x] Interactive questions: recording with a real microphone (0.9.1b)
- [x] Steam profile pictures (0.9.1b)
- [ ] Big videos over a slow connection

### A tidier look
- [x] "Time to answer" on the orange "Your turn!" panel is readable now
- [x] Map pin no longer says "Map" twice
- [x] Clan tags no longer cut names off in the score lists
- [x] Step by step shows what a right answer is worth right now, not always 5 points
- [x] Interactive questions count "Recordings" and "Votes" instead of "Answers"
- [x] All "Next" buttons look the same
- [x] Icons are drawn instead of emoji (some emoji showed up as the wrong shape)
- [x] Even button row for Peek and Reveal answer
- [x] Lobby rules laid out the same way for every group
- [x] Ewige Tabelle shows metres under 1 km off instead of "0.0 km"
- [x] The "?" on question types no longer pops up a long tooltip
- [x] Jokers turned off for the night stay in the waiting room, greyed out ("Off tonight")
